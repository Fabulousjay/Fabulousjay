## How I work
I don't build UI on assumptions. Before I build against an endpoint, I check what it actually returns. On one project that habit caught a customer list where every record came back with the same id, which would have quietly broken the detail pages. I also use AI (mostly Claude) as part of my day-to-day, but as a second pair of eyes rather than an autopilot. I read what it gives me, test it against the real system, and don't ship anything I can't explain.

When something isn't ready on the backend, I say so plainly and keep the UI honest about it, rather than letting a screen look finished when it isn't.
