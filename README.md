I am Ayo, a software engineer who works mostly on the frontend. React, Next.js and TypeScript are what I reach for first. I also write backend code in Laravel (PHP) and Node, so I can work on both sides of an API and speak to the backend team in their own terms.

I studied geophysics, which is how I got into programming, and I have been building web applications professionally since 2021.

## What I am working on

**Zenthom** is a facility maintenance platform, and I am the only frontend developer on it. I built all three dashboards (HQ, facility managers and customers) from the Figma designs, along with the login and onboarding flows: invite links, OTP verification, and tokens that refresh automatically. The backend was still being built while I worked, so I spent a lot of time with the backend engineer agreeing on API contracts and tracking down mismatches. That is 140+ endpoints so far.
Stack: React, TypeScript, Redux Toolkit, React Query, Tailwind. [zenthom.com](https://www.zenthom.com)

**Hutstack** is a property management app for landlords and property managers. I led the frontend: lease tracking, maintenance records, and a financial analytics dashboard with its own set of reusable charts. I also built the marketing site.
Stack: React, TypeScript, Redux Toolkit, ShadCN UI. [hutstack.com](https://hutstack.com)

Before those, I spent three years at Wazobia Technologies, where I designed the template engine for Hivedeck, a no-code website builder used by 500+ businesses.

## How I work

I check what an API actually returns before I build a screen on it. It has saved me more than once. On Zenthom, a customer list came back with the same id on every row, and I caught it before it broke anything. If something is not ready on the backend, I say so and keep the interface honest about it instead of making it look finished.

I am putting more time into testing right now, mainly Cypress.
