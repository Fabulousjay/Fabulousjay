## How I work

<table width="100%">
  <tr>
    <td width="33%" valign="top">
      <h4>Check before building</h4>
      <p>I verify how things actually behave before I build on them, whether that is an API response, a data shape or a design spec. It keeps surprises out of production.</p>
    </td>
    <td width="33%" valign="top">
      <h4>Keep the interface honest</h4>
      <p>When something is not supported yet, I say so and design around what exists, instead of shipping a screen that looks finished but is not.</p>
    </td>
    <td width="33%" valign="top">
      <h4>Use AI with discipline</h4>
      <p>I use AI as a second pair of eyes, not an author. I read and understand everything it produces, and I test it against the real system before it ships.</p>
    </td>
  </tr>
</table>
